# Agent Prompt And Copy Style

## Purpose

这份文件用于约束计划模块以及其他 AI 对话模块的 Prompt、状态文案和卡片按钮文案，避免后续改动再次混入英文表达。

## Rules

- 面向用户展示的状态文案、流式节点标签、卡片按钮文案，默认全部使用中文。
- Prompt 默认使用中文，除非依赖的模型或外部工具明确要求英文。
- 安全校验失败时，不使用报错式英文提示；应使用中文解释原因、给出安全替代方案，并引导用户继续对话。
- 计划相关字段名可以保持代码英文，但用户可见的计划名称、阶段标题、任务描述应优先输出中文。
- 如果读取到的历史规范文件出现编码异常或内容不可直接复用，以本文件作为当前项目的最低执行规范。

## Plan Module Specific

- `translator.py` 中的节点标签统一为中文进度提示。
- `plan_draft.py` 中的系统 Prompt 与用户消息模板统一为中文。
- `conversation.py` 中的计划说明、保存确认、进度解释、安全调整说明统一为中文。
